# cakri-25-solar-sim

## เล่นแบบออฟไลน์ (ครบ 100+ วัตถุ)

1. ดาวน์โหลดหรือโคลนโปรเจ็กต์นี้
2. เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที (ไม่ต้องติดตั้ง)
3. ปรับความเร็วเวลา เลือกโหมดท้องฟ้า และเลือกวัตถุเพื่อดูข้อมูลจริง

### สิ่งที่มีให้ในซิมูเลชัน

- วัตถุจริงมากกว่า 100 รายการ (ดาวฤกษ์ ดาวเคราะห์ ดาวเคราะห์แคระ ดวงจันทร์ ดาวเคราะห์น้อย ดาวหาง และวัตถุแถบไคเปอร์)
- แสดงข้อมูลจริง/ประมาณค่า: ขนาด มวล แรงโน้มถ่วง ระยะทาง Hill radius จุด L คาบ/ความเร็ววงโคจร
- การแสดงผลใช้การปรับสเกลภาพเพื่อให้เห็นวัตถุเล็กและระยะไกลได้ชัดขึ้น
- ข้อมูลฟิสิกส์เสริม เช่น บรรยากาศ สนามแม่เหล็ก วงแหวน การกัดเซาะ และสภาพอากาศ

### โหมดตรวจสอบความสมจริง (Validation)

ภายในหน้าเว็บมีโหมดตรวจสอบที่สามารถนำข้อมูล ephemeris จาก JPL (เช่น Horizons/SBDB) มาเทียบกับผลจำลองได้
โดยระบบจะใช้ leapfrog integrator และรายงานความคลาดเคลื่อนเป็นกิโลเมตร

โครงสร้าง JSON ที่รองรับ (ตัวอย่าง):

```json
{
  "epoch": "2024-01-01T00:00:00Z",
  "dtHours": 1,
  "steps": 24,
  "bodies": [
    {
      "name": "Earth",
      "gm": 3.986004354e14,
      "state": { "x": 1.496e11, "y": 0, "z": 0, "vx": 0, "vy": 29780, "vz": 0 }
    }
  ],
  "reference": {
    "Earth": { "x": 1.496e11, "y": 2.57e9, "z": 0 }
  }
}
```

> ถ้าต้องการพัฒนาเพิ่มเติมสามารถใช้ Vite ได้
